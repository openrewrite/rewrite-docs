# Rewrite Docs

The docs behind [docs.openrewrite.org](https://docs.openrewrite.org/).

## Recipe docs

The recipe docs in the [recipes directory](./docs/recipes/) were generated by the [rewrite-recipe-markdown-generator](https://github.com/openrewrite/rewrite-recipe-markdown-generator), and are no longer regenerated here while the recipe catalog moves to the Code Genome Project. If you wish to change a recipe's name, description, tags, or examples, please update the recipe itself rather than submitting a PR here.

## Generated pages

The [latest versions of every OpenRewrite module](./docs/reference/latest-versions-of-every-openrewrite-module.md) and the versions behind the `{{VERSION_*}}` placeholders in [latest-versions.js](./src/plugins/latest-versions.js) are updated nightly by the [Update docs](./.github/workflows/update-docs.yml) workflow. To update them locally, add your [Code Genome Project](https://artifacts.codegenomeproject.org/maven) credentials to `~/.gradle/gradle.properties` as `codegenomeUsername` and `codegenomePassword`, then run:

```shell
./gradlew updateDocs
```

## Contributing

We encourage you to contribute to our docs! Please feel free to create an issue or open a PR if you find any issues. See the [contributing guide](./CONTRIBUTING.md) for writing standards and how to describe your pull request.

## Local preview

This project uses Docusaurus to manage the documentation. To preview the docs locally, you can run the following command:
```shell
npx docusaurus start;
```
